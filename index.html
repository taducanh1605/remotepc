Controls, permissions and limitations

Focus the video to send keys. Touch acts as a single mouse pointer; right-click and wheel work with a mouse. Fullscreen and keyboard lock are best-effort: browser/OS shortcuts, secure desktops and Ctrl+Alt+Delete cannot be captured. Press Escape to leave fullscreen. Standalone resize changes encoded video only; the native backend can change host display mode subject to ownership.

GitHub Pages serves this app only. The host runs the separate TLS WebRTC gateway. Allow your browser's local-network permission if prompted. A trusted host certificate and reachable UDP ICE path (or your own TURN server) are required.

Microphone is opt-in, requires browser permission, and is available only when the native host advertises a configured virtual-cable sink. It is never enabled automatically. Standalone desktop sound requires a configured Windows system-audio loopback device, not a microphone.

The standalone fallback captures the Windows virtual desktop with FFmpeg, separately from native Sunshine sessions; it does not arbitrate native virtual-display ownership. The native backend requires host lifecycle integration. Access tokens grant desktop control; keep them secret.
