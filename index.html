Controls, permissions and limitations

Focus the video to send keys. Native hosts that advertise support receive independent multitouch contacts and stylus pressure, tilt and eraser input. Standalone capture uses mouse input. The floating menu provides right click, scroll, microphone and manual keyboard controls. Fullscreen and keyboard lock are best-effort: browser/OS shortcuts, secure desktops and Ctrl+Alt+Delete cannot be captured. Press Escape to leave fullscreen. Standalone resize changes encoded video only; the native backend can change host display mode subject to ownership.

GitHub Pages serves this app only. The host runs the separate TLS WebRTC gateway. Allow your browser's local-network permission if prompted. A trusted host certificate and reachable UDP ICE path (or your own TURN server) are required.

Trust host certificate opens the gateway's HTTPS page in a separate window. Any browser certificate warning must be accepted manually; the app never bypasses TLS verification. The page signals completion only to this allowlisted PWA origin.

Microphone is opt-in, requires browser permission, and is available only when the native host advertises a configured virtual-cable sink. It is never enabled automatically. Standalone desktop sound requires a configured Windows system-audio loopback device, not a microphone.

The standalone fallback captures the Windows virtual desktop with FFmpeg, separately from Njk Host's native sessions; it does not arbitrate native virtual-display ownership. Njk Host includes the integrated native browser backend: run its packaged gateway in native mode with matching authentication and trusted TLS. No user coding is required. Access tokens grant desktop control; keep them secret.

Immersive mode requests fullscreen and keyboard lock where available. Exit using the visible Exit button or Escape. Android navigation/back gestures, Windows shortcuts and secure Ctrl+Alt+Delete cannot universally be intercepted. Remote Win, Alt+Tab and Esc buttons inject supported host keys; Ctrl+Alt+Delete is not offered because this host cannot inject the secure sequence. The local magnifier changes only your view, not host resolution. FPS and bitrate are host-configured; no unimplemented quality settings are shown.

Native Windows touch and stylus (including pressure, tilt and eraser) are enabled only when the host advertises those capabilities. The displayed control RTT measures the motion data channel round trip to the gateway; it is not end-to-end video/display latency.
